## About

Personal portfolio built with pure HTML5, CSS3, and vanilla JS — no frameworks, no build step. Self-contained single-file design with a dark editorial aesthetic, an interactive portfolio assistant, HubSpot lead capture, and GA4 analytics.

## Stack

- HTML5 / CSS3 / Vanilla JS (single file)
- GitHub Pages + custom domain (CNAME)
- Schema.org JSON-LD structured data
- SEO: sitemap.xml, robots.txt, canonical, OG tags
- HubSpot Forms API (EU1) · Google Analytics 4

## Structure
